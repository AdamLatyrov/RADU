# RADU

**Русская версия** · [English](README.en.md)

RADU — настольное приложение для Windows, которое запускает команды по голосовым фразам. Команды и действия настраиваются в графическом интерфейсе.

## Скачать и запустить

1. Откройте [последний выпуск RADU](https://github.com/AdamLatyrov/RADU/releases/latest).
2. Скачайте `RADU-Setup.exe` и запустите его. Установщик сам разместит приложение и создаст ярлык в меню «Пуск».
3. Запустите RADU из меню «Пуск» или с рабочего стола, если выбрали такой ярлык.
4. Добавляйте и изменяйте команды на вкладке «Команды».

Выпуск включает интерфейс, голосовой движок и русскую модель распознавания. Для запуска не нужны Python, терминал, командные файлы или отдельная настройка модели. Если предпочитаете переносную версию без установки, скачайте `RADU-Windows.zip` и запустите `RADU.exe` из распакованной папки. Windows может показать предупреждение при первом запуске, так как приложение пока не подписано.

## Данные и конфиденциальность

Команды и записи хранятся локально в профиле Windows. Пользовательские команды, записи, модель распознавания и журналы не входят в исходный репозиторий. Для работы приложения оставьте распакованную папку целиком.

## Состояние проекта

RADU распространяется как предварительная версия для Windows. Точность распознавания зависит от произнесённой фразы, микрофона и модели Vosk.

## Структура исходного кода

- `prototypes/Radu.Wpf/` — интерфейс Windows.
- `assistant/` и `settings.py` — запись речи, распознавание и запуск команд.
- `packaging/` — сборка выпуска.
- `docs/IDEAS_AND_SOURCES.md` — сохранённые идеи и материалы для будущих исследований.

Инструкции по разработке и устройству приложения находятся в [AGENTS.md](AGENTS.md).
