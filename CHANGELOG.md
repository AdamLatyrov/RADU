# Журнал изменений RADU

## v0.1.2-preview.1 — 2026-10-19

- Исправлен контраст кнопки пользовательской палитры. При выбранном белом цвете значок больше не сливается с фоном.
- Цветовая палитра остаётся на тёмной подложке, а значок автоматически выбирает читаемый цвет.
- Добавлен выбор оттенка, насыщенности и яркости перетаскиванием по палитре. HEX-код доступен для точной настройки.
