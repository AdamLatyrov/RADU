# История изменений RADU V3

Обозначение V3 — это поколение проекта, а не номер сборки или релиза. В каталоге RADU-V3 отдельные версии V4 и V5 не обнаружены.

## 13 октября 2026

- Отключены загрузка и проверка акустических эталонов в рабочем запуске. Старые WAV и профили оставлены на месте.
- MFCC, Delta MFCC, Log Mel и DTW убраны из рабочего пути.
- Добавлено отдельное сохранение ссылок на записи, которые прошли часть проверок и провалили остальные. Сами WAV не дублируются.
- В грамматику Vosk добавлены отрицательные варианты фраз. Они не связаны с действиями.
- В диагностическую таблицу добавлены проверки наличия речи, лимита длины, непустой транскрипции, отрицания, полного совпадения, уверенности и запуска действия.
- Меню управления командами больше не записывает акустические эталоны.
- В `data/review/analysis_20261013.md` сохранён разбор последних записей через GigaAM. Полная построчная таблица лежит рядом в CSV.

- Выполнен полный прогон GigaAM v2 RNNT по архивному снимку и наблюдениям RADU. 9282 исходных WAV сопоставлены с 3479 уникальными содержаниями, созданы именованные копии и сводная таблица в `data/gigaam_analysis/run_20261013_100813/`.

## Состояние локальной истории

До этой проверки у RADU V3 не было собственного Git-репозитория. 13 октября создан первый локальный снимок `Зафиксировать начальный снимок RADU V3`. Это фиксирует текущее состояние для будущих откатов, но не восстанавливает историю прежних итераций.

В соседнем ручном проекте `AI-Assistant` есть отдельная история из 12 коммитов. Она не является историей RADU V3 и не содержит изменений этого проекта. Модель и папка данных RADU исключены из Git, их файлы остаются на компьютере.
