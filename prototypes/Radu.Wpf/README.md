# RADU WPF

WPF-интерфейс RADU для Windows. Приложение запускает Python-движок из корня проекта и передаёт ему события управления. Обработка микрофона и распознавание выполняются Python-компонентами.

## Сборка

Нужен .NET 9 SDK для Windows. Откройте `Radu.Wpf.csproj` в Visual Studio или выполните `dotnet build Radu.Wpf.csproj -c Release` из этой папки.

Иконка и начальный каталог команд находятся в проекте. Сборка не зависит от локальной папки релизов.

## Данные пользователя

WPF сохраняет изменённые команды в `%LOCALAPPDATA%\RADU-V3-WPF\commands.json`. При первом запуске создаётся пользовательская копия начального каталога команд. Существующий каталог не заменяется.
