# Визуальная система RADU

## Направление

RADU — точная голосовая консоль. Её характер строится на честной реакции интерфейса на звук и удобной настройке команд. Из Apple Human Interface Guidelines берём ясность, иерархию, последовательность и доступность взаимодействий. Навык Anthropic `frontend-design` используем как проверку против шаблонных компоновок и украшений без функции. Берём принципы, а не внешний вид другого продукта.

## Палитра

| Роль | Значение | Применение |
| --- | --- | --- |
| Графит | `#111416` | Основной фон |
| Поднятый графит | `#1B2024` | Общая поверхность содержимого |
| Графит наведения | `#20262B` | Подсветка активной строки |
| Разделитель | `#30373D` | Границы зон и строк |
| Основной текст | `#F4F5F7` | Названия и заголовки |
| Вторичный текст | `#A7ADB3` | Подсказки, действия и время |
| Акцент пользователя | Выбранный цвет | Навигация, спокойное состояние микрофона, фокус и основные действия |
| Успех и ошибка | Семантические зелёный и красный | Только краткий результат команды |

Основной фон остаётся спокойным. Выбранный пользователем акцент задаёт постоянный характер интерфейса. Зелёный и красный сообщают только о результате команды и не перекрашивают несвязанные элементы. Статус команды на главном экране может показывать длительность от последнего кадра речи до решения по команде; успех окрашивается зелёным, отказ — красным. Палитра акцента не требует текстовой подписи и предлагает готовые оттенки и произвольный выбор.

## Типографика

Используем Segoe UI Variable для естественного вида в Windows. Заголовки страниц — 24 px полужирные, названия команд — 14 px полужирные, основной текст и описание действия — 12–14 px, вторичные подписи — 11–12 px. Заголовок страницы, редактора и списка используют одну шкалу.

## Компоновка

Шапка окна и нижняя навигация остаются на месте. Все страницы используют одинаковые боковые отступы и выравнивание по левому краю. На каждой странице есть один ясный заголовок, одна главная область содержимого и предсказуемое расположение действий. На странице команд число стоит рядом с заголовком без отдельной плашки, а плюс находится в той же строке. Поиск имеет компактную кнопку очистки, которая появляется только при введённом тексте. Поиск и список используют общие границы содержимого. Команды и история оформляются цельными списками с разделителями, без повторяющихся карточек. Поля редактора идут одной колонкой и выровнены по краю списка. Нижняя навигация состоит из трёх одинаковых вертикальных вкладок с единым расположением значка и подписи.

## Геометрия и взаимодействие

У окна скругление 8 px, у общих полей и групп содержимого 4 px, у компактных меню 3 px. Микрофон остаётся круглым, поскольку это главный и узнаваемый элемент продукта. Круглая форма не распространяется на остальные кнопки.

Наведение подсвечивает строку, не меняя её положение. Фокус клавиатуры заметен и использует выбранный акцент. Удаление команды доступно отдельной иконкой корзины, становится красной при наведении и всегда требует встроенного подтверждения. Удаление каталожной команды сохраняет WAV и распознанные записи истории. Контекстное меню истории использует плоскую тёмную подсветку без системного синего состояния. История обновляется автоматически при открытии и по изменению журнала запусков, без кнопки ручного обновления. Новые записи не останавливают текущее воспроизведение. Папка WAV открывается через контекстное меню строки. Длинные списки прокручиваются плавно по пикселям, а история сохраняет виртуализацию строк. Движение показывает уровень звука, результат команды или изменение после действия. Если платформа сообщает о предпочтении уменьшенного движения, анимации учитывают его.

## Проверка согласованности

- Каждый цвет объясняет иерархию, действие или состояние голоса.
- Команды и история используют одинаковые отступы, типографику, разделители и поведение при наведении.
- Поиск, списки и поля редактора выровнены по одной линии содержимого.
- Для повторяющихся действий используются согласованные размеры Lucide-иконок и доступные подписи.
- У декоративных подписей, свечений, границ и карточек есть ясная функция.
- При изменении размера окна сохраняется порядок чтения и видимость нижней навигации.
